Choose and trust your tools

The shared plugin catalog connects available tools to your personal workflow.

A shared catalog

Administrators review plugin packages and control which tools are available on the site. Each plugin's inventory helps you see what its package contains.

Your own workflow

Enable the approved tools you need. Your navigation shows your selected workflows, and related pages stay together as tabs within each tool.

Signed plugin packages

Create a signing key in User settings, sign your package locally with the provided CLI and submit the signed archive for review. Browser plugins run their work in a restricted background worker.
