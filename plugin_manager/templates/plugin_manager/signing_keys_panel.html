Sign a package with the CLI

Download the signing CLI and an example package.

uv run --with cryptography cadevil_sign.py sign plugin.zip --key your-key.cadevil-key.json --output plugin.signed.zip

The CLI asks for your passphrase locally. Publish the signed archive on the Plugins page.
