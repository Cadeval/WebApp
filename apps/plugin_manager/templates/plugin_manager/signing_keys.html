Sign your package locally

Download the signing CLI and example package.

uv run --with cryptography cadevil_sign.py sign plugin.zip --key your-key.cadevil-key.json --output plugin.signed.zip

The CLI prompts for your passphrase locally. Upload the resulting signed archive to the store. It signs every file, including plugin.json, and refuses to overwrite the input archive.
