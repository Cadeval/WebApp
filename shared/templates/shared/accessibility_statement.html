Accessibility

Cadevil aims to support keyboard navigation, screen readers and reduced motion. These improvements are tested in the main application journeys; they are not a claim of complete WCAG conformance.

Keyboard and page navigation

Use the first “Skip to content” link to reach the main page. Tab and Shift+Tab move between controls. Workspace tabs support arrow keys, Home and End; Enter or Space opens the selected page. Page changes move focus to the new heading or main landmark; workspace tab changes retain focus on the selected tab.

Models, results and motion

The 3D viewer includes a labelled building-part selector and readable material details. You can inspect these without choosing a part with the pointer. The viewer displays its supported keyboard controls. Calculation results, validation issues and map building lists are also available as text.

Visible focus indicators and operating-system reduced-motion preferences are respected. Canvas rendering, maps, third-party visualizations and administrator-only Django pages may still have accessibility limitations.

Report a barrier

Contact the site operator with the page, task, browser and assistive technology involved. Use synthetic examples and omit private models or credentials. The security contact page provides the current contact channel.
